# Міні-проєкт: підключення сенсора і актуатора, відладчик

Перший міні-проєкт: світлочутливий вимикач, який спрацьовує на зміну освітленості. ESP32-S3 вимірює
освітленість фоторезистором і замикає реле, коли темнішає, та розмикає його, коли знову світлішає.

## Апаратна частина

| Сигнал       | Вивід          | Опис                                   |
| ------------ | -------------- | -------------------------------------- |
| Освітленість | IO4 (ADC1_CH3) | Дільник LDR/10k, послаблення 12 dB     |
| Ключ реле    | IO5            | Базовий резистор 10k на BC547B         |
| Калібрування | IO0            | Штатна кнопка BOOT, внутрішня підтяжка |

Плата - ESP32-S3-DevKitC-1 з модулем N16R8.

## Калібрування

Утримуйте BOOT протягом 2с, щоб почати: реле блимає тричі, після чого замикається й чекає.

1. Затемніть сенсор, коротке натискання. Фіксує темнову точку, блимає один раз і розмикає реле.
2. Освітіть сенсор, коротке натискання. Фіксує світлову точку й зберігає результат.

Без збереженого калібрування використовуються "фабричні" налаштування.

## Збірка

```
pio run -t upload -t monitor
```
