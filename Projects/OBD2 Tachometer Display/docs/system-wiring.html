The subtle part

Why the DLC's ground pins stay empty

CAN is differential, but it isn't ground-free — both ends need a common-mode reference within a few volts of each other. On a motorcycle that reference already exists: the ECU is bolted to the same chassis your battery negative goes to, and your buck's negative goes there too. The reference is closed through the frame before you wire anything.

Running a second ground wire from DLC pin 4 or 5 doesn't add safety. It creates a second return path in parallel with the chassis, and any current flowing in it develops a voltage that shifts your transceiver's reference relative to the ECU's — which is exactly the noise the differential pair exists to reject.

Downstream of the controller

What else lands on the ESP32

Beyond the four transceiver wires, the board carries the 1.28" round LCD (GC9A01) over 4-wire SPI — SCLK, MOSI, DC, CS, RST, plus a PWM backlight line — the BH1750 light sensor over I²C, and two buttons. That is about a dozen GPIOs in total, so pin budget is no longer a concern; still assign CAN TX/RX first, then I²C, then the two buttons, then the panel, and keep the buttons off the strapping pins.

Each button gets a 10 kΩ pull-up to 3V3 and a 100 nF cap to ground at the GPIO, with the switch pulling the pin low — about a 1 ms time constant. That RC is not optional here: the handlebar run is an unshielded wire alongside ignition leads, and software debounce alone will register phantom presses from coil EMI.

Keep buttons off the strapping pins Avoid GPIO 0, 3, 45 and 46. A button held down at power-on drives a strapping pin to the wrong level and the chip boots into download mode instead of running your firmware. GPIO 0 is the classic version of this mistake.
